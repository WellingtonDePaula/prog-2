# Objetivo

Desenvolver um sistema para gerenciar um pequeno mercado, ele deve ter as seguintes funções:

+ Gerenciamento de estoque
+ Cadastrar produtos
+ Realiza venda
+ Fecha caixa
+ Consulta preço

# Usuário

 + Gerente (faz tudo:cadastra usuários, cadastra produtos, faz venda, consulta preço, mexe no estoque)
 + Vendedor (realiza venda, consulta preço, atualiza estoque)
 + Cliente (Consulta preço) -> Feito

# Sistema

  + Produtos - marca, nome, descrição, peso, lote(lote), valor_custo, valor_venda, quantidade.
